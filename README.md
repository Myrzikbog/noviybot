# ⚔️ Тёмный Век: Сага о Выживании (Dark Age RPG)

> Интеллектуальная текстовая процедурная RPG в Telegram с искусственным интеллектом Google Gemini и механикой настольных ролевых игр (d20).

Специально спроектирована под легкие сервера (**1 ГБ RAM, 2 vCPU, 30 ГБ SSD**). Бот потребляет всего **~45–65 МБ ОЗУ** в работе, мгновенно отвечает и сохраняет всю историю в локальную базу данных SQLite.

---

## 🌟 Почему этот бот «умный» и не скатывается в бред?

Большинство обычных AI-ботов страдают от «синдрома всемогущего игрока» и забывчивости. В этом боте реализована **гибридная архитектура**:

1. **Движок на стороне сервера (SQLite + Python):**
   - Отслеживает физическое состояние (HP 0–100), уровень рассудка (Sanity 0–100), золото и инвентарь.
   - Читерить бесполезно: если у вас нет отмычки в рюкзаке, бот не позволит её применить.
2. **Броски кубика d20 (D&D Mechanics):**
   - Каждое рискованное действие бросает кубик `d20 + модификатор навыка` (Сила, Ловкость, Интеллект).
   - Результат (критический провал, неудача, частичный успех, триумф) передается нейросети в качестве строгого условия. Gemini не может просто так «подыграть» игроку.
3. **Защита от бреда и взлома промпта (Anti-Jailbreak):**
   - Если игрок пишет безумные вещи (*«я достал автомат и взорвал планету»*), AI интерпретирует это как горячечный бред истощенного разума или падение рассудка, наказывает персонажа и возвращает в суровую реальность средневековья.
4. **Долговременная летопись (Chronicle):**
   - Ключевые судьбоносные выборы (убийство барона, предательство союзника, спасение деревни) навсегда сохраняются в летопись персонажа и подмешиваются в контекст AI.
5. **Свобода выбора:**
   - На каждом шагу доступны 3–4 динамические кнопки от ИИ **плюс кнопка «✍️ Своё действие»**, позволяющая написать любой поступок текстом.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.10+:
```bash
pip install -r requirements.txt
```

### 2. Настройка ключей
Откройте файл `.env` в текстовом редакторе и укажите:
```env
BOT_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
GEMINI_MODEL=gemini-2.5-flash
```

* **BOT_TOKEN**: Получите бесплатно у [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`).
* **GEMINI_API_KEY**: Получите бесплатно в [Google AI Studio](https://aistudio.google.com/app/apikey).
* **GEMINI_MODEL**: Рекомендуется `gemini-2.5-flash` или `gemini-3.8-flash` (работает быстро и поддерживает структурированный JSON).

### 3. Запуск бота
```bash
python bot.py
```
Перейдите в вашего бота в Telegram и отправьте команду `/start`!

## 🖥️ Деплой на VPS (1 ГБ RAM, 2 vCPU, 30 ГБ SSD)

### Шаг 1: Настройка Swap (файла подкачки на 2 ГБ)
На Linux VPS с 1 ГБ ОЗУ обязательно создайте swap-файл (защитит от пиковых скачков памяти):
```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### Шаг 2: Клонирование и настройка окружения
```bash
git clone <ваш_репозиторий> /opt/noviybot
cd /opt/noviybot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
nano .env   # вставьте ваши токены
```

### Шаг 3: Автозапуск через Systemd (24/7 в фоне)
Создайте файл сервиса:
```bash
sudo nano /etc/systemd/system/darkage_bot.service
```
Вставьте конфигурацию:
```ini
[Unit]
Description=Dark Age Telegram RPG Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/noviybot
ExecStart=/opt/noviybot/venv/bin/python /opt/noviybot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запустите и включите автозапуск:
```bash
sudo systemctl daemon-reload
sudo systemctl enable darkage_bot
sudo systemctl start darkage_bot
```

Проверить статус:
```bash
sudo systemctl status darkage_bot
```
