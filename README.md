# ⚔️ Тёмный Век: Сага о Выживании (Dark Age RPG)

> Интеллектуальная текстовая процедурная RPG в Telegram с искусственным интеллектом Google Gemini и механикой настольных ролевых игр (d20).

Специально спроектирована под легкие сервера (**1 ГБ RAM, 2 vCPU, 30 ГБ SSD**). Бот потребляет всего **~45–65 МБ ОЗУ** в работе, мгновенно отвечает и сохраняет всю историю в локальную базу данных SQLite.

---

## 🌟 Почему этот бот «умный» и не скатывается в бред?

Большинство обычных AI-ботов страдают от «синдрома всемогущего игрока» и забывчивости. В этом боте реализована **гибридная архитектура**:

1. **Движок на стороне сервера (SQLite + Python):**
   - Отслеживает физическое состояние (HP 0–100), уровень рассудка (Sanity 0–100), золото и инвентарь.
   - Читерить бесполезно: если у вас нет отмычки в рюкзаке, бот не позволит её применить.
2. **Броски кубика d20 (D&D Mechanics):**
   - Каждое рискованное действие бросает кубик `d20 + модификатор навыка` (Сила, Ловкость, Интеллект).
   - Результат (критический провал, неудача, частичный успех, триумф) передается нейросети в качестве строгого условия. Gemini не может просто так «подыграть» игроку.
3. **⚔️ Боевая система и боссы:**
   - При встрече с опасными тварями (чумные волки, инквизиторы, главари мародеров) запускается режим дуэли с отдельной шкалой здоровья врага (`⚔️ ВРАГ: Чумной волк [🟥🟥🟥░░░] (35/70 HP)`).
   - Игрок выбирает тактические приемы (силовой удар, парирование, скрытный финт, отступление).
4. **🎒 Интерактивный рюкзак и лечение:**
   - Предметы из сумки можно мгновенно применить прямо из меню рюкзака: съесть сало (`+25 HP`), выпить настойку полыни (`+25 Рассудка`), перевязать раны или выпить эликсир.
5. **🧠 Смерть от безумия (Sanity Mechanics):**
   - Если рассудок падает до 0, персонаж безвозвратно сходит с ума и погибает, а его имя навсегда заносится на Кладбище павших.
6. **⭐ Прокачка уровней и защита от читов (XP & Level Up):**
   - За победы над врагами и преодоление опасностей начисляется опыт.
   - При Level Up игрок распределяет очко характеристик (+1 к Силе, Ловкости или Интеллекту) с восстановлением +25 HP и +25 Рассудка.
7. **🛒 Лавка придорожного торговца:**
   - Возможность покупать еду (+HP), успокаивающие настойки (+Sanity), бинты, отмычки и факелы (заблокирована во время активного боя).
8. **🏆 Зал славы (`/top`) и ⚰️ Кладбище павших (`/graveyard`):**
   - Глобальный рейтинг самых живучих героев всех игроков и архив нелепых/эпичных смертей.
9. **📱 Оптимизированный мобильный UX и команды Telegram:**
   - Компактный интерфейс без нагромождения кнопок, меню системных команд (`/start`, `/help`, `/top`, `/graveyard`, `/restart`) и индикатор «печатает...» во время бросков кубика.
10. **100% Асинхронность, Таймауты и WAL SQLite:**
    - Защита от зависаний (таймаут 20 сек), полное экранирование HTML и WAL-режим базы данных.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.10+:
```bash
pip install -r requirements.txt
```

### 2. Настройка ключей
Откройте файл `.env` в текстовом редакторе и укажите:
```env
BOT_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
GEMINI_MODEL=gemini-2.5-flash
```

* **BOT_TOKEN**: Получите бесплатно у [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`).
* **GEMINI_API_KEY**: Получите бесплатно в [Google AI Studio](https://aistudio.google.com/app/apikey).
* **GEMINI_MODEL**: Рекомендуется `gemini-2.5-flash` или `gemini-3.8-flash` (работает быстро и поддерживает структурированный JSON).

### 3. Запуск бота
```bash
python bot.py
```
Перейдите в вашего бота в Telegram и отправьте команду `/start`!

## 🖥️ Быстрый деплой на VPS (1 ГБ RAM, 2 vCPU, 30 ГБ SSD)

Мы подготовили **автоматический скрипт деплоя** (`deploy.sh`), который сделает всё за вас:
1. Создаст и включит **2 ГБ Swap** (файл подкачки на SSD с тюнингом под низкую задержку).
2. Установит Python 3, venv, git и все зависимости.
3. Запросит ваши токены `BOT_TOKEN` и `GEMINI_API_KEY` (если `.env` ещё не настроен).
4. Создаст и запустит фоновую службу `systemd` (бот будет работать 24/7 и автоматически перезапускаться при перезагрузке сервера).

### Команда быстрого запуска на вашем сервере (одной строкой):

```bash
curl -sSL https://raw.githubusercontent.com/Myrzikbog/noviybot/main/deploy.sh | sudo bash
```

*Или через клонирование репозитория:*
```bash
git clone https://github.com/Myrzikbog/noviybot.git
cd noviybot
sudo bash deploy.sh
```

## 🛠️ Управление ботом на VPS

* **Проверить статус службы:**
  ```bash
  sudo systemctl status darkage_bot
  ```
* **Смотреть живые логи:**
  ```bash
  sudo journalctl -u darkage_bot -f
  ```
* **Перезапустить бота:**
  ```bash
  sudo systemctl restart darkage_bot
  ```
* **Остановить бота:**
  ```bash
  sudo systemctl stop darkage_bot
  ```
